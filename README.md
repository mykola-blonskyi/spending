# Spending

Personal and family expense tracking: an installable, offline-capable PWA with a NestJS API,
deployed to the owner's VPS. Sign-in goes through `login.blonskyi.dev`.

- Architecture: `docs/architecture.md`
- Decisions (ADRs): `docs/decisions.md`
- Running, checks, deployment: `docs/operations.md`
- Domain: `knowledge/domain-model.md`, `knowledge/business-rules.md`
- Work plan: `plans/current.md`

Quick start:

```bash
pnpm install && pnpm db:up && pnpm dev
```
